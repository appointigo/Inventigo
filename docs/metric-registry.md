# Stockiva canonical metric registry

## Global accounting and date policy

- Currency is INR and is aggregated at paise precision. Persisted Prisma `Decimal` values are converted only at calculation boundaries; totals use integer minor units and round to two decimals.
- Business dates use `Asia/Kolkata` (`UTC+05:30`). UI date ranges are inclusive business dates and database queries use `[start, endExclusive)`.
- Recognized sales include `COMPLETED`, `EXCHANGED`, and `REFUNDED` sale rows because returns/exchanges are represented as separate signed events. Draft/cancelled/void rows are excluded.
- A return obligation, its settlement, and merchandise returned are different facts. A refund is cash movement only when a negative `SalePayment` and its linked settlement exist.
- Store-period metrics require an explicit store. Organization-current finance metrics may intentionally aggregate all stores and are labelled as such.

## Return and refund state transitions

| Event                 |                                   SalePayment | RefundLiability      | RefundSettlement                  |      Outstanding |
| --------------------- | --------------------------------------------: | -------------------- | --------------------------------- | ---------------: |
| Immediate POS refund  | One or more negative rows totaling the refund | Created as `SETTLED` | One per actual payment allocation |                0 |
| Deferred refund       |                                          None | `PENDING`            | None                              |      Full refund |
| Partial settlement    |     Negative payment for amount actually paid | `PARTIAL`            | One settlement for that payment   | Unpaid remainder |
| Final settlement      |             Negative payment for final amount | `SETTLED`            | One settlement for that payment   |                0 |
| Return without refund |                                          None | None                 | None                              |                0 |
