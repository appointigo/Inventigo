## Canonical dependency flow

`Sale + ReturnTransaction` → canonical signed financial events → Sales Analytics → Dashboard and Profitability.

`SalePayment` → positive Collections. `RefundSettlement` → Refunds Paid; an immediate POS negative SalePayment is linked evidence for that same settlement and is not added again. Neither feeds Revenue.

`StockEntry` → complete variant set → Dashboard, Stock report, Alerts and current inventory valuation.
