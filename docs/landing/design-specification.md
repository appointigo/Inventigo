# Landing design specification

## Composition

- Desktop content gutters: 5vw.
- Hero: minimum 705px, asymmetric 40/60 content-to-product composition.
- Section spacing: 70–90px desktop; 55–70px mobile.
- Desktop breakpoints: 1050px for reflow and 760px for mobile navigation/single-column layouts.

## Type

- System grotesk stack for reliable loading and close reference proportions.
- Hero: responsive 58–94px, 0.89 line-height, heavy weight and tight negative tracking.
- Section headings: responsive 38–66px, 1.0 line-height.
- Body: 16–18px; operational labels 12–14px.
- Georgia italic is used only for “Smarter”, matching the reference's contrasting editorial gesture.

## Surfaces

- Warm off-white page, white cards, charcoal/forest feature panels.
- Borders are 1px neutral gray-green.
- Cards use 13–24px radii and low-opacity ambient shadows.
- Motion is limited to hover elevation and is disabled under `prefers-reduced-motion`.

## Responsive behavior

- Tablet collapses hero and feature/workflow grids while retaining visual hierarchy.
- Mobile uses a menu button, vertical CTAs, single-column features/pricing/forms, simplified product mock and horizontal snap-scrolling industry cards.
- All major containers use constrained grids and the page hides no overflowing content as a substitute for layout correction.
