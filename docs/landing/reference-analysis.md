# Reference analysis

The supplied reference is a desktop concept collage rather than one literal browser viewport. Its main visual grammar is:

- A light, photographic hero split between editorial copy and a large angled product presentation.
- A compact navigation band with black type and a dark pill CTA.
- Oversized, tightly tracked grotesk headlines; one italic serif word provides contrast.
- Warm cream and stone surfaces, forest-green actions, black-green feature panels and very restrained borders.
- Product photography appears in clipped cards with consistent commercial lighting.
- The industry strip is deliberately denser than the hero and acts as a transition into a dark feature block.
- Buttons are substantial, rounded rectangles or pills; cards use medium radii and soft low-opacity shadows.
- Product UI is bright, compact and data-dense, with a dark vertical navigation rail.

Conceptual elements not treated as factual include testimonial counts, store counts, processed-sales figures, uptime claims and named customer quotes. They were not reproduced because the repository does not substantiate them.
